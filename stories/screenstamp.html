Screenstamp

github.com/maclir/screenstamp ↗

One big high-resolution Dell, with the laptop tucked underneath it as the second screen. The same arrangement at every desk, and macOS treats each one like it has never seen it before.

The setup never changes. Same monitor, same resolution, laptop below rather than beside. But plug into it at a different desk and everything is slightly wrong. The scaling is off. macOS has decided the laptop is to the left. The refresh rate has quietly dropped. So the day starts with five minutes of dragging little blue rectangles around Display Settings.

What makes it grating is that the knowledge exists. macOS just ties its memory to one specific physical monitor rather than to the shape of the setup, so an identical desk counts as a new one.

What it does

It installs in one line:

sh -c "$(curl -fsSL https://raw.githubusercontent.com/maclir/screenstamp/main/install.sh)"

Then set a desk up properly once and save it:

  • screenstamp save office — records resolution, refresh rate, colour depth, scaling, rotation, enabled state and arrangement.
  • screenstamp load office — stamps it onto whatever compatible screens you're plugged into now.

Stamp is the operative word. A profile is not tied to one physical display, so a layout saved at one desk lands correctly on a matching setup anywhere else. It is a small tool that fixes one annoyance completely. It is on GitHub and installs in one line.
